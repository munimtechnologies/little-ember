# Little Ember

A small GDevelop 5 game made for **GDevelop BIG Game Jam #10** (theme "Keep It Alive", 6-15 November 2026).

It is 9 PM on a cold mountain night, and Little Ember, a campfire spirit, is the only warm thing for miles.
Keep it alive until 6 AM: tap falling twigs and pinecones to feed it, and tap snowflakes, heavy snow clumps
(twice) and gusts of wind before they reach the flame. One night lasts about two and a half minutes.
Mouse or touch (landscape).

- Play on itch.io: https://munimv2.itch.io/little-ember
- Play on gd.games: https://gd.games/munimv2/little-ember
- Jam: https://itch.io/jam/gdevelop-big-game-jam-10

## How it was made

The game was written by AI agents (Anthropic Claude) working for MV2 of Munim, Inc. Nothing was drawn or
recorded by hand and no asset packs were used: every image, sound and the music are generated by `art.mjs`.
The GDevelop project file is written by `build-game.mjs` with MV2's open-source
[gdwrite](https://github.com/munimtechnologies/gdwrite) helpers (Apache-2.0, published before the jam).
All game rules live in one JavaScript event, `game-code.js`, which GDevelop runs every frame.

| File | What it does |
|---|---|
| `game-code.js` | The whole game: spawning, input, fire math, end screens, HUD. Rules advance in fixed steps of at most 0.05 s. |
| `art.mjs` | Pixel-art images (sky, mountains, trees, flame, face, twigs, snow, HUD) and WAV sounds/music, made in code. |
| `build-game.mjs` | Writes `game.json` plus every PNG/WAV it uses, and the itch.io cover. |
| `steps/desktop.json`, `steps/phone.json` | Scripted play-throughs for gdwrite's headless test harness (a fast bot, a slow and sloppy bot, and an idle player). |
| `page.txt` | The text used on the itch.io and gd.games pages. |

## Build and test

Needs Node 20. In a folder with the files above:

```sh
# gdwrite v0.3.0 helpers and test harness
for f in gdwrite.mjs png.mjs wav.mjs pixelart.mjs tune.mjs harness/export.mjs harness/play.mjs harness/expect.mjs; do
  mkdir -p "$(dirname "$f")"
  curl -fsSL "https://raw.githubusercontent.com/munimtechnologies/gdwrite/v0.3.0/$f" -o "$f"
done
npm install gdcore-tools@2.0.0-gd-v5.6.269-autobuild playwright@1.47.0
npx playwright install --with-deps chromium

# GDevelop's own example projects supply the object and scene templates
git clone --depth 1 --filter=blob:none --sparse https://github.com/GDevelopApp/GDevelop-examples.git ex
(cd ex && git sparse-checkout set examples/breakout examples/platformer)

node build-game.mjs game ex/examples/breakout/breakout.json ex/examples/platformer/platformer.json
node harness/export.mjs game/game.json build          # HTML5 export
node harness/play.mjs build steps/desktop.json out     # desktop play-through + screenshots
node harness/play.mjs build steps/phone.json out       # phone-sized play-through
```

`game/game.json` also opens in the GDevelop 5 desktop app. The gd.games release was published from that
app on 7 November 2026 from the same project file, unchanged.

The sandbox build of 7 November 2026 passed all 27 desktop checks and all 14 phone checks with no page or
console errors. The fast test bot (170 ms reactions) reached dawn with 2,520 points, the slow bot (650 ms,
up to 18 px off target) reached dawn with 2,924, and an idle player's fire went out after 25 seconds.

`window.__ember` exposes test-only hooks (seed, speed, bots). Players always play at normal speed.
